# SpeedXpat

Network diagnostics and capability assessment for latency, jitter, throughput, DNS, and connection quality.

## Run Locally

Prerequisite: Node.js 22 or later.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run lint
```

Production hosting uses Vercel. Deploy with `npx vercel --prod` from the project directory.
